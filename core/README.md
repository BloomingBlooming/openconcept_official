# 本体のバージョン別配布 / Versioned Application Distributions

最新版は **V2.6.1** です。通常版とV2.6.0からの更新版を掲載しています。V2.6.0通常版はプラグインID制限の不具合により配布を停止しました。V2.5.0とV2.6.0は旧環境からの中間更新版だけを保持しています。

The latest version is **V2.6.1**, available as a full installation and an upgrade from V2.6.0. The full V2.6.0 release has been withdrawn because of its plugin ID restriction defect. Only intermediate upgrades remain available for V2.5.0 and V2.6.0.

新規設置にはV2.6.1を使用してください。V2.4.1からは2.5.0、2.6.0、2.6.1の順に更新します。[V2.5.0の変更前ハッシュに関する説明](2.5.0/README.md)も確認してください。

Use V2.6.1 for new installations. Upgrade V2.4.1 through 2.5.0 and 2.6.0 to 2.6.1, noting the [V2.5.0 before-hash information](2.5.0/README.md).

配布物はOpenConceptの `Dist/core/` から `core/<version>/` へ配置し、[先頭のダウンロード一覧](../README.md)と揃えています。ZIP、SHA-256、manifest付き展開済みファイルを含みます。V2.5.0とV2.6.0の通常版は公開対象から削除し、各バージョンへの更新版は継続して提供します。配布物をここで直接編集しません。

Distributions are copied from OpenConcept's `Dist/core/` into `core/<version>/`, matching the [main download list](../README.md). Each includes a ZIP, checksum and unpacked files with a manifest. The full V2.5.0 and V2.6.0 releases have been removed; upgrade packages for each version remain available. Packaged contents are not edited here.
