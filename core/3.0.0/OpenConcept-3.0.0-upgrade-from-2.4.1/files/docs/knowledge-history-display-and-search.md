# 全文履歴の表示と検索

2026-09-12の「全文保存を維持し、履歴表示と検索の取りこぼしを改善する」という指示への対応。

## 保存と表示

`revisions` の全文保存、版ID、本文、属性、旧添付の保持、正本出力は変更しない。保存済みの履歴を削除・統合・差分形式へ変換しない。

「記録と履歴」は検索条件に一致した履歴をすべて取得してから、同じページを一つの結果へまとめる。展開すると、各保存ID・日時・アイコン・カバーと本文の種類数を確認できる。まとめる対象はページ履歴のみで、発言・追記・会話などは別の記録として扱う。表示件数とページ送りはこの結果単位であり、ページ内の保存履歴を途中のページで分断しない。表示される件数は現在の権限で検索に一致したものだけであり、ページの全保存件数とは限らない。

詳細は保存された全文を読み出し、同じページの次の保存履歴と属性・本文を比較する。次の保存履歴がなければ現在のページと比較する。比較先を明示し、条件に一致しなかった隣の保存履歴にもリンクする。現在のページ閲覧権限を検証してから返す。古い履歴で未記録の属性は推測せず、比較対象外であることを示す。保存処理や、ページへ書き戻す既存の「復元」処理はこの変更の対象に含まない。

## 継続できる検索

`GET api.php?action=knowledge-search&scan=1` は `items`、`scan_cursor`、`complete`、`date_basis` を返す。`scan_cursor` がある間は同じ検索条件と `cursor` を送って継続する。取得件数は1〜500件、走査は1回2,000行または約2秒で区切るが、検索全体の件数による打ち切りは設けない。0件のバッチでも、`complete=false` なら続きがある。

取得位置は主キーによる継続方式で、前の行を毎回OFFSETで読み直さない。カーソルはセッション内の鍵で認証付き暗号化し、権限のない行の主キーや走査件数を公開しない。検索条件・利用者の変更や改変されたカーソルを拒否し、各取得で現在の認証・閲覧権限を再確認する。セッションが変わった場合は検索をやり直す。

画面は続きのバッチを自動で取得し、検索中・完了・中断を区別する。中断した場合は取得済み結果を保持して「検索を続ける」から再開できる。検索語の変更後に古い応答が戻っても採用しない。本文の抜粋は最初の400文字に固定せず、一致した語の近くを表示する。

検索はリクエスト単位の一貫した読み取りであり、複数リクエストを通じた固定時点の正本スナップショットではない。検索中に追加・変更された記録も含む最新の結果が必要な場合は再検索する。ブラウザーの保持メモリとサーバー環境による実行制限は残る。

既存の `scan` を指定しないOFFSET APIは互換性のため維持する。従来の20,000走査行・5秒・2,000一致件の制限と `truncated` はその形式に限って残る。新しい画面と履歴AI検索は継続方式を使用する。

## AI検索

検索語ごとに最初の30件だけを候補にする処理を廃止し、候補の選定前に続きの記録も走査する。同じページ・タイトル・本文・保存者を持つ履歴を一つの候補として扱う。別ページ、異なる本文、異なる保存者、訂正等の追記がある履歴、会話の別発言は統合しない。期間等の条件は統合前に適用する。

候補には元の履歴ID・本文ハッシュ・抜粋位置・一致した版の件数を保持する。離れた検索語が一つの抜粋に収まらない場合は別の抜粋も作る。回答の前後に従来どおり原文と権限を再検証する。同じ本文が繰り返し保存された回数を、独立した複数の裏付けと扱わない。

AI候補の件数と回答に渡す文字数には既存の上限があるため、全件が一つの回答に採用される保証ではない。履歴の走査・候補化が15秒以内に終わらなければエラーとして中断し、未完了の検索を「根拠なし」や完了済みの回答にしない。全記録の確認は履歴画面で行える。

## 検証

- `KnowledgeHistoryCoverageTest.php`: 20,005件の不一致履歴の後にある2,050件の同一本文、別本文・別ページを欠落なく取得。空バッチ継続、改変カーソル、非公開記録、期間条件、訂正付き版、離れた検索語、隣接版比較、旧メタ情報の欠落、全文保持を確認。
- `KnowledgeHistoryPaginationUiTest.cjs`: バッチ境界をまたぐ6件のグループ化、全IDへのリンク、10/25/50件表示、途中失敗と再開、古い応答の無視、安全な文字列表示、変更点、ミラー一致を確認。
- `KnowledgeHistoryHttpTest.php`: 認証付きHTTPで継続取得と比較、5言語のラベル、従来のOFFSET API、正本出力、権限変更を確認。
- `KnowledgeHistoryTest.php`、`AiSearchTest.php`、`I18nTest.php`: 既存履歴・AI検索・原本出力／隔離復元と多言語化の回帰確認。
- ローカルの合成データを実ブラウザーで確認。同一本文の6件が1つの検索結果になり、各保存版のカバー変更と本文不変を確認できる。

V2.6.1の履歴表示・検索改善版に含める。検証は隔離環境で行い、公開サイトの利用者データには変更を加えていない。
