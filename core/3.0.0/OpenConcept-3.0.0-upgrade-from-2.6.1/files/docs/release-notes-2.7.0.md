# OpenConcept V2.7.0

> 履歴記録：V2.7.0は単独配布せず、V2.6.1以降の差分・V2.6.2の開発内容とともに[V3.0.0](release-notes-3.0.0.md)へ集約しました。以下は開発当時の記録です。 / Historical record: 2.7.0 was not released separately; its changes are included in 3.0.0 together with the changes since 2.6.1 and the 2.6.2 development work.

## メンバー招待・ログイン・写真の改善

- 管理者の「設定 > メール」に送信元、SMTPサーバー、ポート、暗号化、アカウント、パスワード、返信先、タイムアウトの設定を追加。保存済み設定から管理者本人へテストメールを送信できる。
- SMTP設定は既存のSecretストアを用いて暗号化して保存し、パスワードは画面・APIレスポンス・監査ログへ返さない。既存の環境変数設定は初回保存まで利用できる。
- ローカル起動のログ専用ガードを維持。ログへの記録と実際のメール送信を画面で区別する。
- 招待時にメンバーの言語を選択。件名・本文とリンク先のログイン画面に反映する。招待再送・パスワード再設定・アカウント復活時も対象メンバーの言語を使用する。
- ログイン前と初回パスワード変更画面に言語選択を追加。`?lang=vi-VN` 等の共有リンクを使用でき、検証エラーとパスワード変更後も選択言語を保持する。
- ログイン・初期セットアップ・初回パスワード変更・設定・招待の言語選択ラベルは、全言語で英語の「Language」に統一。言語名の選択肢は各言語の自国語で表示する。
- プロフィール写真はサーバー側で長辺256px以内・128KiB以内へ縮小・再エンコードする。JPEGの向き、PNG/WebPの透明度を保持し、不正画像や圧縮失敗時は既存アイコンを保持する。
- 既存の大きな写真は初回表示時に軽量画像を生成・キャッシュする。元画像とDB参照は保持する。
- V2.6.2で開発した履歴カレンダーの言語対応とフロートNavi 1.2.3の状態保持を継続する。プラグインの版番号は独立管理する。

## 運用上の変更

PHPのGD拡張とJPEG/PNG/WebPの対応を有効にしてください。同梱Docker構成はGDを含みます。GDが未導入の場合は新しい写真の保存時に設定不足を案内し、既存写真の閲覧は維持します。

SMTP設定は「保存」の後に「テストメール送信」で検証します。成功はSMTPサーバーによる受付を表すため、受信トレイで到着も確認してください。SSL/TLSまたはSTARTTLSを使用します。暗号化なしのSMTPはローカルのテストサーバーに限ります。

公式UI言語は英語・日本語・ベトナム語・韓国語・簡体字中国語です。新規招待APIで言語を省略した場合は英語になります。既存メンバーの保存済み言語、既存URL、DB構成、環境・Docker volume名は維持します。

全体監査で見つかったRAG設定、API・プラグインのエラー、通知、新規ページの既定値、Markdown・印刷・PDFの固定表示も5言語に対応しました。AI検索・ページ操作の固定案内や要約指示も対象です。言語切替で人間が入力した本文・名称・分類・ファイル名を自動翻訳することはありません。

5言語の招待・初回ログイン・再設定、疑似SMTPの正常／失敗経路、画像の圧縮と既存写真保持に加え、追加修正のHTTP・描画・通知・出力を検証しています。メールの実配送・受信は実環境で確認してください。詳細と検証範囲は [検証記録](validation-2.7.0.md) を参照してください。
